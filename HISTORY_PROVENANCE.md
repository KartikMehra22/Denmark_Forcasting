# History provenance

This repository was created through a retrospective code import on 18 November 2026. It is not the original day-by-day development history.

The initial 55 commits use reconstructed author dates between 26 October and 18 November 2026 to organise existing code into reviewable stages. Their committer dates record the actual import. The assigned author dates are not evidence of when code or experiments were originally written or run. The original stage labels remain in `IMPORT_MANIFEST.json`.

The original imported source is available in the repository's earlier commits. Later changes reorganise and format the working code, so the current files should not be expected to have the original byte-for-byte hashes. The retained research artifacts include the original source snapshots and recorded hashes for provenance.

Data, API responses, forecasts, weights and reports are not published in this code-only repository. They are kept in the separate reproducibility package.
